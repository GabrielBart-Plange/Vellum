# Mobile UX Options for Secondary Content

When optimizing the responsive design for mobile screens, secondary features (like the Spotlight Author, Community Goal, or Promoted items) can't sit in a sidebar due to limited screen width. Here are the main options for including them without cluttering the mobile view:

### 1. The "Bottom Stack" (Most Common)
Move the entire sidebar content to the very bottom of the page, right above the footer.
- **Pros:** Super easy to implement. Users who scroll to the bottom naturally discover it.
- **Cons:** Users have to scroll past all the main content to see it, so engagement might be low.

### 2. A Dedicated Tab in the Hamburger Menu
Add a new link inside the mobile hamburger menu called **"Community"** or **"Discover"**. Clicking it takes the user to a dedicated page housing these secondary features.
- **Pros:** Keeps the homepage incredibly clean. Gives features a dedicated, focused space.
- **Cons:** Adds an extra click for the user to find them.

### 3. Swipeable Carousels (Horizontal Scrolling)
Condense the secondary features into smaller cards and place them in a horizontal, swipeable row (e.g., right below the Hero section).
- **Pros:** Saves massive amounts of vertical space. Looks very modern.
- **Cons:** Can be easily ignored if users scroll down quickly.

### 4. A Slide-Up "Drawer" (Modal/Bottom Sheet)
Add a small, floating button at the bottom of the screen (e.g., "Community Stats"). When tapped, a panel slides up over the screen showing the content.
- **Pros:** It's always accessible but never in the way.
- **Cons:** Can sometimes conflict with the device's native swipe gestures or feel intrusive if not designed carefully.
